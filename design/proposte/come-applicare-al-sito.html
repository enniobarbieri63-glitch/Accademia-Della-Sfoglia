Palloncini sfogline

Un solo blocco di codice, nessuna libreria da installare. I volti sono disegnati al momento dal browser, oppure li sostituisci con le foto vere delle sfogline. Qui sotto sta girando davvero: e' lo stesso codice che copierai.

Anteprima dal vivo · strato "sezione"

Come si applica

  1. Copia il blocco in fondo a questa pagina.

  2. Incollalo nel sito subito prima di </body>. Su WordPress, Wix o Squarespace usa un riquadro "HTML personalizzato"; se hai un tema, va bene anche il footer.

  3. Regola gli attributi del <div> — quanti palloncini, che velocita', se stanno dietro a tutta la pagina o dentro a un riquadro.

Le foto vere al posto dei disegni

Due strade, e si possono mescolare. La prima: elenchi gli indirizzi delle immagini nell'attributo.

<div data-palloncini-sfogline
     data-foto="/foto/rina.jpg, /foto/lucia.jpg, /foto/anna.jpg"
     data-foto-quota="0.5"></div>

La seconda, comoda se le immagini le gestisci dal pannello del sito: metti dei <img> dentro al div. Vengono nascosti e usati dentro ai palloncini.

<div data-palloncini-sfogline>
  <img src="/foto/rina.jpg" alt="">
  <img src="/foto/lucia.jpg" alt="">
</div>

data-foto-quota decide quanta parte dei palloncini usa le foto: 1 tutti, 0.4 quattro su dieci e gli altri restano disegnati — la mescolanza e' quella che rende meglio, perche' i disegni fanno respirare i ritratti.

Le foto rendono al meglio quadrate, viso al centro, 500-800 px di lato: vengono ritagliate a cerchio. E, ovviamente, servono il consenso delle sfogline ritratte e foto di cui hai i diritti.

Il suono

Le risatine e i "tuc" dei palloncini sono sintetizzati dal browser: nessun file da scaricare, nessuna licenza da pagare. Si accendono con data-suono="si" e partono solo dopo il primo tocco del visitatore, perche' i browser bloccano l'audio automatico — ed e' giusto cosi'.

La sintesi pero' ha un tetto: una risata vera, con le sue irregolarita' di fiato, non si imita con degli oscillatori. Per quella serve una registrazione. Mettila in data-suono-file e parte da sola ogni otto-venti secondi, come una risata che scappa; con data-suono-modo="anello" diventa invece un sottofondo continuo.

<div data-palloncini-sfogline
     data-suono-file="/audio/risate-bimbi.mp3"
     data-suono-modo="ogni-tanto"
     data-suono-volume="0.35"></div>
Come procurarsela: registrarla al corso con il telefono (dieci secondi bastano, e serve il consenso dei genitori dei bambini ripresi) oppure prenderla da una libreria di suoni con licenza. Formato mp3, mono, sotto i 200 KB: il sito resta leggero.

Dai sempre un interruttore a chi visita il sito: due bottoni tuoi, collegati cosi'.

<button onclick="PalloncinISfogline.suono(true)">Accendi il suono</button>
<button onclick="PalloncinISfogline.suono(false)">Silenzio</button>

Le vocine

Con data-voci="si" ogni tanto un palloncino dice una frase, usando le voci di sintesi gia' installate nel dispositivo di chi guarda: niente da scaricare, ma la voce cambia da telefono a computer e su qualche apparecchio l'italiano non c'e'. Trattalo come un di piu', non come una certezza.

<div data-palloncini-sfogline
     data-voci="si"
     data-voci-frasi="ih ih ih|che bella sfoglia|guarda come volo"></div>

<button onclick="PalloncinISfogline.voci(false)">Basta vocine</button>

  /* ---------- suono: risatine e tuc sintetizzati, oppure un file vero ---------- */
  function creaSuono(opz) {
    var ctx = null, master = null, fiato = null, traccia = null, acceso = false, vociAccese = false;
    var prossimaVoce = 0, prossimoFile = Infinity;
    var ultimoTuc = 0, ultimaRisata = 0, prossimaRisata = 0;

   function apri() {
      if (ctx) return;
      var AC = window.AudioContext || window.webkitAudioContext;
      if (!AC) return;
      ctx = new AC();
      master = ctx.createGain();
      master.gain.value = 0.9 * opz.volume / 0.35;
      var caldo = ctx.createBiquadFilter();
      caldo.type = "lowpass";
      caldo.frequency.value = 6200;

      /* un filo di stanza intorno alle voci */
      var coda = ctx.createConvolver();
      var lung = Math.floor(ctx.sampleRate * 0.5);
      var imp = ctx.createBuffer(2, lung, ctx.sampleRate);
      for (var c = 0; c < 2; c++) {
        var dati = imp.getChannelData(c);
        for (var i = 0; i < lung; i++) {
          dati[i] = (Math.random() * 2 - 1) * Math.pow(1 - i / lung, 2.6);
        }
      }
      coda.buffer = imp;
      var quantaCoda = ctx.createGain();
      quantaCoda.gain.value = 0.22;

      master.connect(caldo);
      caldo.connect(ctx.destination);
      caldo.connect(coda);
      coda.connect(quantaCoda);
      quantaCoda.connect(ctx.destination);

      /* fiato: un secondo di rumore, riusato per tutte le risate */
      fiato = ctx.createBuffer(1, ctx.sampleRate, ctx.sampleRate);
      var f = fiato.getChannelData(0);
      for (var j = 0; j < f.length; j++) f[j] = Math.random() * 2 - 1;
    }

   /* il "tuc" morbido del palloncino che tocca il bordo */
    function tuc(tono, forza) {
      var t = ctx.currentTime;
      var o = ctx.createOscillator(), g = ctx.createGain();
      o.type = "sine";
      o.frequency.setValueAtTime(tono, t);
      o.frequency.exponentialRampToValueAtTime(tono * 0.5, t + 0.09);
      g.gain.setValueAtTime(0.0001, t);
      g.gain.exponentialRampToValueAtTime(0.1 * forza, t + 0.008);
      g.gain.exponentialRampToValueAtTime(0.0001, t + 0.14);
      o.connect(g); g.connect(master);
      o.start(t); o.stop(t + 0.16);
    }

   /* Una risatina di bambina, costruita come si costruisce una voce:
       le corde vocali (l onda a dente di sega), la bocca (tre formanti)
       e il fiato fra una sillaba e l altra. Niente strilli: sillabe
       larghe, tono che scende, volume basso. */
    function sillaba(t0, f0, vocale, forza) {
      var o = ctx.createOscillator();
      o.type = "sawtooth";
      o.frequency.setValueAtTime(f0 * 1.04, t0);
      o.frequency.exponentialRampToValueAtTime(f0 * 0.88, t0 + 0.17);

      var vib = ctx.createOscillator(), vibG = ctx.createGain();
      vib.frequency.value = 5.2 + Math.random() * 1.4;
      vibG.gain.value = f0 * 0.014;
      vib.connect(vibG); vibG.connect(o.frequency);

      var glottide = ctx.createBiquadFilter();
      glottide.type = "lowpass";
      glottide.frequency.value = 3400;
      glottide.Q.value = 0.6;

      var busta = ctx.createGain();
      busta.gain.setValueAtTime(0.0001, t0);
      busta.gain.exponentialRampToValueAtTime(0.5 * forza, t0 + 0.028);
      busta.gain.exponentialRampToValueAtTime(0.0001, t0 + 0.19);

      o.connect(glottide);
      /* i tre formanti: cambiano la vocale da "hi" a "he" */
      var F = vocale === "i" ? [370, 2750, 3400] : [560, 2150, 3050];
      var pesi = [1, 0.42, 0.2];
      for (var k = 0; k < 3; k++) {
        var b = ctx.createBiquadFilter();
        b.type = "bandpass";
        b.frequency.value = F[k] * (0.97 + Math.random() * 0.06);
        b.Q.value = 7 + k * 3;
        var gg = ctx.createGain();
        gg.gain.value = pesi[k];
        glottide.connect(b); b.connect(gg); gg.connect(busta);
      }
      busta.connect(master);
      o.start(t0); o.stop(t0 + 0.22);
      vib.start(t0); vib.stop(t0 + 0.22);

      /* la "h": un soffio corto davanti alla sillaba */
      if (fiato) {
        var n = ctx.createBufferSource();
        n.buffer = fiato;
        n.loop = true;
        var nf = ctx.createBiquadFilter();
        nf.type = "bandpass";
        nf.frequency.value = 1900;
        nf.Q.value = 0.9;
        var ng = ctx.createGain();
        ng.gain.setValueAtTime(0.0001, t0 - 0.03);
        ng.gain.exponentialRampToValueAtTime(0.055 * forza, t0 + 0.01);
        ng.gain.exponentialRampToValueAtTime(0.0001, t0 + 0.1);
        n.connect(nf); nf.connect(ng); ng.connect(master);
        n.start(Math.max(0, t0 - 0.03)); n.stop(t0 + 0.12);
      }
    }

    function risatina(tono) {
      var t = ctx.currentTime + 0.03;
      var colpi = 3 + Math.floor(Math.random() * 3);
      var vocale = Math.random() < 0.6 ? "i" : "e";
      for (var i = 0; i < colpi; i++) {
        var f0 = tono * Math.pow(0.955, i) * (0.99 + Math.random() * 0.02);
        var forza = i === 0 ? 1 : 0.92 - i * 0.06;
        sillaba(t, f0, vocale, forza);
        t += 0.175 + Math.random() * 0.045;
      }
    }

    /* Voci di sintesi: quelle installate nel dispositivo di chi guarda.
       Nessun file da scaricare, ma la voce cambia da telefono a computer
       e su qualche apparecchio l italiano non c e: e' un di piu', non una
       certezza. */
    function voce(frase) {
      if (!window.speechSynthesis) return;
      var u = new SpeechSynthesisUtterance(frase);
      var elenco = window.speechSynthesis.getVoices().filter(function (v) {
        return /^it/i.test(v.lang);
      });
      if (elenco.length) u.voice = elenco[Math.floor(Math.random() * elenco.length)];
      u.lang = "it-IT";
      u.pitch = 1.55 + Math.random() * 0.4;
      u.rate = 0.92 + Math.random() * 0.18;
      u.volume = opz.volume + 0.15;
      window.speechSynthesis.speak(u);
    }

    return {
      attivo: function () { return acceso; },
      accendiVoci: function (si) {
        vociAccese = !!si;
        if (vociAccese) prossimaVoce = performance.now() + 1500;
        else if (window.speechSynthesis) window.speechSynthesis.cancel();
      },
      accendi: function (si) {
        acceso = !!si;
        if (acceso) {
          if (opz.sintetico) {
            apri();
            if (ctx && ctx.state === "suspended") ctx.resume();
            prossimaRisata = performance.now() + 1200;
          }
          if (opz.file) {
            if (!traccia) {
              traccia = new Audio(opz.file);
              traccia.preload = "auto";
              traccia.loop = opz.modo === "anello";
              traccia.volume = opz.volume;
            }
            if (opz.modo === "anello") {
              var pr = traccia.play();
              if (pr && pr.catch) pr.catch(function () {});
            } else {
              prossimoFile = performance.now() + 1500;
            }
          }
        } else if (traccia) {
          traccia.pause();
        }
      },
      rimbalzo: function (p) {
        if (!acceso || !ctx || document.hidden) return;
        var ora = performance.now();
        if (ora - ultimoTuc < 240) return;
        ultimoTuc = ora;
        tuc(300 / p.profondita, Math.min(1, p.profondita));
        if (Math.random() < 0.14 && ora - ultimaRisata > 1600) {
          ultimaRisata = ora;
          risatina(360 + Math.random() * 90);
        }
      },
      battito: function () {
        var adesso = performance.now();
        /* la registrazione vera: una risata ogni tanto, non un tappeto continuo */
        if (acceso && traccia && opz.modo !== "anello" && !document.hidden && adesso > prossimoFile) {
          prossimoFile = adesso + 8000 + Math.random() * 12000;
          try { traccia.currentTime = 0; } catch (e) {}
          var pf = traccia.play();
          if (pf && pf.catch) pf.catch(function () {});
        }
        if (vociAccese && !document.hidden && adesso > prossimaVoce) {
          prossimaVoce = adesso + 7000 + Math.random() * 8000;
          voce(opz.frasi[Math.floor(Math.random() * opz.frasi.length)]);
        }
        if (!acceso || !ctx || document.hidden) return;
        var ora = performance.now();
        if (ora < prossimaRisata) return;
        prossimaRisata = ora + 3500 + Math.random() * 5000;
        ultimaRisata = ora;
        risatina(360 + Math.random() * 90);
      }
    };
  }

  var scene = [];
  window.PalloncinISfogline = {
    suono: function (si) {
      scene.forEach(function (s) { s.accendi(si); });
    },
    voci: function (si) {
      scene.forEach(function (s) { s.accendiVoci(si); });
    }
  };

  /* ---------- una scena per ogni contenitore ---------- */
  function avvia(nodo) {
    if (nodo.dataset.avviato) return;
    nodo.dataset.avviato = "1";

    var opz = {
      numero: Math.max(1, Math.min(120, parseInt(nodo.dataset.numero, 10) || 18)),
      velocita: parseFloat(nodo.dataset.velocita) || 1,
      dimensione: parseFloat(nodo.dataset.dimensione) || 1,
      filo: nodo.dataset.filo !== "no",
      puntatore: nodo.dataset.puntatore !== "no",
      opacita: nodo.dataset.opacita === undefined ? 1 : parseFloat(nodo.dataset.opacita),
      sezione: nodo.dataset.strato === "sezione",
      foto: [],
      quotaFoto: 0
    };

    /* foto dall'attributo e dalle <img> messe dentro al contenitore */
    (nodo.dataset.foto || "").split(",").forEach(function (u) {
      u = u.trim();
      if (u) opz.foto.push(u);
    });
    Array.prototype.slice.call(nodo.querySelectorAll("img")).forEach(function (im) {
      var u = im.currentSrc || im.getAttribute("src");
      if (u) opz.foto.push(u);
      im.remove();
    });
    if (opz.foto.length) {
      var q = parseFloat(nodo.dataset.fotoQuota);
      opz.quotaFoto = isNaN(q) ? 1 : Math.max(0, Math.min(1, q));
    }

    var vol = parseFloat(nodo.dataset.suonoVolume);
    var frasi = (nodo.dataset.vociFrasi || "ih ih ih|ah ah ah|eh eh eh|che bella sfoglia|guarda come volo")
      .split("|").map(function (f) { return f.trim(); }).filter(Boolean);
    var suono = creaSuono({
      sintetico: nodo.dataset.suono === "si",
      file: (nodo.dataset.suonoFile || "").trim(),
      volume: isNaN(vol) ? 0.35 : Math.max(0, Math.min(1, vol)),
      modo: nodo.dataset.suonoModo === "anello" ? "anello" : "ogni-tanto",
      frasi: frasi
    });
    scene.push(suono);

    /* i browser lasciano suonare solo dopo il primo gesto del visitatore */
    if (nodo.dataset.suono === "si" || nodo.dataset.voci === "si" || (nodo.dataset.suonoFile || "").trim()) {
      var sveglia = function () {
        if (nodo.dataset.suono === "si" || (nodo.dataset.suonoFile || "").trim()) suono.accendi(true);
        if (nodo.dataset.voci === "si") suono.accendiVoci(true);
        ["pointerdown", "keydown", "touchstart"].forEach(function (e) {
          window.removeEventListener(e, sveglia);
        });
      };
      ["pointerdown", "keydown", "touchstart"].forEach(function (e) {
        window.addEventListener(e, sveglia, { once: false });
      });
    }

    nodo.style.position = opz.sezione ? "absolute" : "fixed";
    nodo.style.top = nodo.style.left = nodo.style.right = nodo.style.bottom = "0";
    nodo.style.overflow = "hidden";
    nodo.style.pointerEvents = "none";
    nodo.style.opacity = String(opz.opacita);
    nodo.style.zIndex = nodo.dataset.livello || (opz.sezione ? "0" : "-1");
    if (opz.sezione) {
      var padre = nodo.parentElement;
      if (padre && getComputedStyle(padre).position === "static") padre.style.position = "relative";
    }

    var palloncini = [];
    var contatore = 0;
    var semeScena = Math.floor(Math.random() * 1e9);
    var L = 0, H = 0;
    var visibile = true;
    var puntatore = { x: -9999, y: -9999, attivo: false };
    var motoRidotto = window.matchMedia("(prefers-reduced-motion: reduce)").matches;

    function misuraScena() {
      var r = nodo.getBoundingClientRect();
      L = r.width || window.innerWidth;
      H = r.height || window.innerHeight;
    }

    function misura(p) {
      var lato = Math.min(L, H);
      p.larghezza = Math.max(46, lato * 0.15 * p.profondita * opz.dimensione);
      p.raggio = p.larghezza * 0.44;
      p.el.style.width = p.larghezza + "px";
    }

    function nuovo(i) {
      var r = seme((semeScena ^ Math.imul(i + 1, 2654435761)) >>> 0);
      r(); r(); r();
      var profondita = 0.55 + Math.random() * 0.6;
      var el = document.createElement("div");
      el.style.position = "absolute";
      el.style.top = el.style.left = "0";
      el.style.transformOrigin = "50% 33.333%";
      el.style.willChange = "transform";
      el.style.filter = "drop-shadow(0 8px 12px rgba(42,31,23,.16))";
      var conFoto = opz.foto.length && r() < opz.quotaFoto;
      el.innerHTML = conFoto
        ? disegnaFoto(r, ++contatore, opz.filo, opz.foto[i % opz.foto.length])
        : disegnaVolto(r, ++contatore, opz.filo);
      el.firstChild.setAttribute("style", "display:block;width:100%;height:auto");
      nodo.appendChild(el);

      var angolo = Math.random() * Math.PI * 2;
      var base = 0.35 + Math.random() * 0.7;
      var p = {
        el: el,
        profondita: profondita,
        larghezza: 0,
        raggio: 0,
        x: (0.08 + Math.random() * 0.84) * L,
        y: (0.08 + Math.random() * 0.84) * H,
        vx: Math.cos(angolo) * base * profondita,
        vy: Math.sin(angolo) * base * profondita,
        fase: Math.random() * Math.PI * 2,
        ondeggio: 3 + Math.random() * 6,
        ritmo: 0.006 + Math.random() * 0.008
      };
      misura(p);
      el.style.zIndex = String(Math.round(profondita * 100));
      return p;
    }

    var ultimo = performance.now();

    function passo(ora) {
      var dt = Math.min(48, ora - ultimo) / 16.6667;
      ultimo = ora;

      if (visibile && !document.hidden) {
        for (var i = 0; i < palloncini.length; i++) {
          var p = palloncini[i];
          var v = opz.velocita * (motoRidotto ? 0.3 : 1);
          p.x += p.vx * dt * v;
          p.y += p.vy * dt * v;

          if (opz.puntatore && puntatore.attivo) {
            var dx = p.x - puntatore.x, dy = p.y - puntatore.y;
            var d2 = dx * dx + dy * dy, R = 170;
            if (d2 < R * R) {
              var d = Math.sqrt(d2) || 1, f = (1 - d / R) * 0.7;
              p.vx += (dx / d) * f;
              p.vy += (dy / d) * f;
            }
          }

          var urto = false;
          if (p.x < p.raggio) { p.x = p.raggio; p.vx = Math.abs(p.vx); p.vy += (Math.random() - 0.5) * 0.12; urto = true; }
          if (p.x > L - p.raggio) { p.x = L - p.raggio; p.vx = -Math.abs(p.vx); p.vy += (Math.random() - 0.5) * 0.12; urto = true; }
          if (p.y < p.raggio) { p.y = p.raggio; p.vy = Math.abs(p.vy); p.vx += (Math.random() - 0.5) * 0.12; urto = true; }
          if (p.y > H - p.raggio) { p.y = H - p.raggio; p.vy = -Math.abs(p.vy); p.vx += (Math.random() - 0.5) * 0.12; urto = true; }
          if (urto) suono.rimbalzo(p);

          var s = Math.hypot(p.vx, p.vy);
          var max = 2.4 * p.profondita, min = 0.22 * p.profondita;
          if (s > max) { p.vx *= max / s; p.vy *= max / s; }
          if (s < min && s > 0) { p.vx *= min / s; p.vy *= min / s; }

          p.fase += p.ritmo * dt * (motoRidotto ? 0.4 : 1);
          var rot = motoRidotto ? 0 : Math.sin(p.fase) * p.ondeggio;
          p.el.style.transform =
            "translate3d(" + (p.x - p.larghezza / 2) + "px," + (p.y - p.larghezza / 2) + "px,0) rotate(" + rot.toFixed(2) + "deg)";
        }
        suono.battito();
      }
      requestAnimationFrame(passo);
    }

    misuraScena();
    for (var i = 0; i < opz.numero; i++) palloncini.push(nuovo(i));

    window.addEventListener("resize", function () {
      misuraScena();
      palloncini.forEach(function (p) {
        misura(p);
        p.x = Math.min(Math.max(p.x, p.raggio), L - p.raggio);
        p.y = Math.min(Math.max(p.y, p.raggio), H - p.raggio);
      });
    });

    if (opz.puntatore) {
      window.addEventListener("pointermove", function (e) {
        var r = nodo.getBoundingClientRect();
        puntatore.x = e.clientX - r.left;
        puntatore.y = e.clientY - r.top;
        puntatore.attivo = true;
      });
      window.addEventListener("pointerleave", function () { puntatore.attivo = false; });
    }

    /* ferma il disegno quando la scena non si vede: niente batteria sprecata */
    if (window.IntersectionObserver) {
      new IntersectionObserver(function (voci) {
        visibile = voci[0].isIntersecting;
      }).observe(nodo);
    }

    requestAnimationFrame(passo);
  }

  function avviaTutti() {
    var nodi = document.querySelectorAll("[data-palloncini-sfogline]");
    for (var i = 0; i < nodi.length; i++) avvia(nodi[i]);
  }

  if (document.readyState === "loading") {
    document.addEventListener("DOMContentLoaded", avviaTutti);
  } else {
    avviaTutti();
  }
})();
</script>

La pagina rispetta chi ha chiesto meno animazioni nelle impostazioni del sistema: in quel caso i palloncini rallentano e smettono di dondolare. Quando la scena esce dallo schermo il disegno si ferma, per non consumare batteria.
