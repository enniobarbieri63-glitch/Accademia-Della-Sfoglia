Palloncini sfogline

Un solo blocco di codice, nessuna libreria da installare. I volti sono disegnati al momento dal browser, oppure li sostituisci con le foto vere delle sfogline. Qui sotto sta girando davvero: e' lo stesso codice che copierai.

Anteprima dal vivo · strato "sezione"

Come si applica

  1. Copia il blocco in fondo a questa pagina.

  2. Incollalo nel sito subito prima di </body>. Su WordPress, Wix o Squarespace usa un riquadro "HTML personalizzato"; se hai un tema, va bene anche il footer.

  3. Regola gli attributi del <div> — quanti palloncini, che velocita', se stanno dietro a tutta la pagina o dentro a un riquadro.

Le foto vere al posto dei disegni

Due strade, e si possono mescolare. La prima: elenchi gli indirizzi delle immagini nell'attributo.

<div data-palloncini-sfogline
     data-foto="/foto/rina.jpg, /foto/lucia.jpg, /foto/anna.jpg"
     data-foto-quota="0.5"></div>

La seconda, comoda se le immagini le gestisci dal pannello del sito: metti dei <img> dentro al div. Vengono nascosti e usati dentro ai palloncini.

<div data-palloncini-sfogline>
  <img src="/foto/rina.jpg" alt="">
  <img src="/foto/lucia.jpg" alt="">
</div>

data-foto-quota decide quanta parte dei palloncini usa le foto: 1 tutti, 0.4 quattro su dieci e gli altri restano disegnati — la mescolanza e' quella che rende meglio, perche' i disegni fanno respirare i ritratti.

Le foto rendono al meglio quadrate, viso al centro, 500-800 px di lato: vengono ritagliate a cerchio. E, ovviamente, servono il consenso delle sfogline ritratte e foto di cui hai i diritti.

Il suono

Le risatine e i "tuc" dei palloncini sono sintetizzati dal browser: nessun file da scaricare, nessuna licenza da pagare. Nel blocco il suono e' gia' acceso (data-suono="si") e parte al primo tocco del visitatore, perche' i browser bloccano l'audio automatico — ed e' giusto cosi'. Metti "no" se lo vuoi muto.

La sintesi pero' ha un tetto: una risata vera, con le sue irregolarita' di fiato, non si imita con degli oscillatori. Per quella serve una registrazione. Mettila in data-suono-file e parte da sola ogni otto-venti secondi, come una risata che scappa; con data-suono-modo="anello" diventa invece un sottofondo continuo.

<div data-palloncini-sfogline
     data-suono-file="/audio/risate-bimbi.mp3"
     data-suono-modo="ogni-tanto"
     data-suono-volume="0.35"></div>
Come procurarsela: registrarla al corso con il telefono (dieci secondi bastano, e serve il consenso dei genitori dei bambini ripresi) oppure prenderla da una libreria di suoni con licenza. Formato mp3, mono, sotto i 200 KB: il sito resta leggero.

Dai sempre un interruttore a chi visita il sito: due bottoni tuoi, collegati cosi'.

<button onclick="PalloncinISfogline.suono(true)">Accendi il suono</button>
<button onclick="PalloncinISfogline.suono(false)">Silenzio</button>

Le vocine

Con data-voci="si" ogni tanto un palloncino dice una frase. La voce non viene dal dispositivo: e' costruita qui dentro suono per suono — le regole di pronuncia dell'italiano, poi le formanti che scivolano da un suono all'altro senza scatti, il tono che sale sull'accento e scende alla fine. Quindi suona uguale su ogni telefono e ogni computer. Le vocali ripetute si allungano cantando: scrivi bellooooo e lo canta.

<div data-palloncini-sfogline
     data-voci="si"
     data-voci-frasi="guarda come volo|ohhh che bellooooo|vieni anche tuuuuu"></div>

<button onclick="PalloncinISfogline.voci(false)">Basta vocine</button>

      if (!AC) return;
      ctx = new AC();
      master = ctx.createGain();
      master.gain.value = 0.9 * opz.volume / 0.35;
      var caldo = ctx.createBiquadFilter();
      caldo.type = "lowpass";
      caldo.frequency.value = 6200;

      /* un filo di stanza intorno alle voci */
      var coda = ctx.createConvolver();
      var lung = Math.floor(ctx.sampleRate * 0.5);
      var imp = ctx.createBuffer(2, lung, ctx.sampleRate);
      for (var c = 0; c < 2; c++) {
        var dati = imp.getChannelData(c);
        for (var i = 0; i < lung; i++) {
          dati[i] = (Math.random() * 2 - 1) * Math.pow(1 - i / lung, 2.6);
        }
      }
      coda.buffer = imp;

      quantaCoda.gain.value = 0.22;

      caldo.connect(ctx.destination);
      caldo.connect(coda);
      coda.connect(quantaCoda);
      quantaCoda.connect(ctx.destination);

      var t = ctx.currentTime;
      var o = ctx.createOscillator(), g = ctx.createGain();
      o.type = "sine";
      o.frequency.setValueAtTime(tono, t);
      o.frequency.exponentialRampToValueAtTime(tono * 0.5, t + 0.09);
      g.gain.setValueAtTime(0.0001, t);
      g.gain.exponentialRampToValueAtTime(0.1 * forza, t + 0.008);
      g.gain.exponentialRampToValueAtTime(0.0001, t + 0.14);

       risata la voce cambia grana (ora spinta, ora soffiata), qualche
       sillaba passa dal naso, il tono non sta mai fermo e alla fine si
       sente il respiro che rientra. Le raffiche si costruiscono una
       volta sola, all accensione del suono, e poi si suonano. */
    function gauss() {
      return (Math.random() + Math.random() + Math.random() + Math.random() - 2) / 1.2;
    }

    function costruisciRisata(par) {
      var sr = ctx.sampleRate;
      var n = Math.ceil(sr * 2.4);
      var buf = ctx.createBuffer(1, n, sr);
      var out = buf.getChannelData(0);
      var sorgente = new Float32Array(n);
      var apertura = new Float32Array(n);
      var nasale = new Float32Array(n);
      var i, j, t = 0.05;
      var sillabe = 3 + Math.floor(Math.random() * 3);

      for (var s = 0; s < sillabe; s++) {
        var ultima = s === sillabe - 1;
        var f0s = par.f0 * Math.pow(0.95, s) * (1 + gauss() * 0.025);
        var amp = (s === 0 ? 1 : Math.max(0.4, 1 - s * 0.13)) * (0.85 + Math.random() * 0.3);
        var aria = par.fiato * (1 + s * 0.26);
        var OQ = 0.5 + Math.random() * 0.28 + s * 0.03;    /* quanto restano aperte le corde */
        var tilt = 0.55 - OQ * 0.35;
        var conNaso = Math.random() < 0.4;
        var duro = Math.random() < 0.35;                   /* colpo di glottide invece della "h" */
        var attacco = duro ? 0.025 : 0.07;
        var lunga = 0.15 * (0.8 + Math.random() * 0.45);
        var i0 = Math.floor(t * sr), len = Math.floor(lunga * sr);
        var fase = 0, periodo = 0, nn = 0, deriva = 0, lpf = 0;

        for (i = 0; i < len; i++) {
          var u = i / len;
          if (i % 220 === 0) deriva = deriva * 0.85 + gauss() * 0.012;
          var f0 = f0s * (1 + 0.1 * Math.sin(Math.PI * Math.min(1, u * 1.5)) - 0.24 * u + deriva);
          if (ultima && u > 0.55) f0 *= 0.82;
          var busta = u < attacco ? u / attacco : Math.pow(1 - (u - attacco) / (1 - attacco), 1.75);
          if (fase <= 0) {
            var doppio = ultima && u > 0.6 && Math.random() < 0.45;   /* il gracchio finale */
            periodo = sr / f0 * (doppio ? 2 : 1) * (1 + gauss() * 0.03);
            fase = periodo;
            nn = 0;
          }
          var T1 = periodo * OQ * 0.72, T2 = periodo * OQ * 0.28, g = 0;
          if (nn < T1) g = 0.5 * (1 - Math.cos(Math.PI * nn / T1));
          else if (nn < T1 + T2) g = Math.cos(Math.PI * (nn - T1) / (2 * T2));
          var aperta = nn < T1 + T2 ? 1 : 0.22;
          var soffio = (Math.random() * 2 - 1) * aria * aperta * (u < 0.14 ? (duro ? 0.8 : 2.8) : 1);
          var grezzo = g * (1 + gauss() * 0.06) + soffio;
          lpf += (grezzo - lpf) * (0.25 + tilt);
          if (i0 + i < n) {
            sorgente[i0 + i] += lpf * busta * amp;
            apertura[i0 + i] = Math.max(0.05, 1 - u * 0.85);
            nasale[i0 + i] = conNaso ? Math.min(1, u * 1.4) : 0;
          }
          nn++;
          fase--;
        }

        var gap = Math.floor(0.032 * sr);
        for (i = 0; i < gap && i0 + len + i < n; i++) {
          sorgente[i0 + len + i] += (Math.random() * 2 - 1) * aria * 0.55 * (1 - i / gap);
          apertura[i0 + len + i] = 0.2;
        }
        t += 0.19 * (0.8 + Math.random() * 0.4);
      }

      /* il respiro che rientra, con un filo di voce dentro */
      var ir = Math.floor((t + 0.03) * sr), lr = Math.floor(0.32 * sr);
      var fase2 = 0, nn2 = 0;
      for (i = 0; i < lr && ir + i < n; i++) {
        var uu = i / lr, invil = Math.sin(Math.PI * uu);
        var v = (Math.random() * 2 - 1) * par.fiato * 2.4 * invil * 0.6;
        if (fase2 <= 0) { fase2 = sr / (230 + 150 * uu); nn2 = 0; }
        var Tr = fase2 * 0.4;
        if (nn2 < Tr) v += 0.5 * (1 - Math.cos(Math.PI * nn2 / Tr)) * 0.12 * invil;
        nn2++;
        fase2--;
        sorgente[ir + i] += v;
        apertura[ir + i] = 0.3 + 0.35 * uu;
      }

      /* bocca, gola e naso: formanti mobili, scalati sulla statura di chi ride */
      var poli = [{y1:0,y2:0},{y1:0,y2:0},{y1:0,y2:0},{y1:0,y2:0},{y1:0,y2:0}];
      var a1 = [], a2 = [], A = [], gn = 0, rz = 0.96, thz = 0, zx1 = 0, zx2 = 0, prec = 0;
      for (i = 0; i < n; i++) {
        if (i % 64 === 0) {
          var ap = apertura[i], k = par.tratto;
          var F = [(560 + 400 * ap) * k, (1560 + 260 * ap) * k, 2950 * k, 3900 * k, 1000 * k];
          var B = [100 + 40 * (1 - ap), 140, 190, 260, 120];
          a1 = []; a2 = []; A = [];
          for (j = 0; j < 5; j++) {
            var r = Math.exp(-Math.PI * B[j] / sr), th = 2 * Math.PI * F[j] / sr;
            a1.push(2 * r * Math.cos(th));
            a2.push(-r * r);
            A.push(1 - a1[j] - a2[j]);
          }
          gn = nasale[i] * 0.5;
          thz = 2 * Math.PI * (820 * k) / sr;
        }
        var x = sorgente[i];
        if (gn > 0) {
          var z = x - 2 * rz * Math.cos(thz) * zx1 + rz * rz * zx2;
          zx2 = zx1; zx1 = x;
          x = x * (1 - gn) + z * gn;
        } else {
          zx2 = zx1; zx1 = x;
        }
        var orale = x, f, y;
        for (j = 0; j < 4; j++) {
          f = poli[j];
          y = A[j] * orale + a1[j] * f.y1 + a2[j] * f.y2;
          f.y2 = f.y1; f.y1 = y; orale = y;
        }
        var nas = 0;
        if (gn > 0) {
          f = poli[4];
          nas = A[4] * x + a1[4] * f.y1 + a2[4] * f.y2;
          f.y2 = f.y1; f.y1 = nas;
        }
        var somma = orale + nas * gn * 0.6;
        out[i] = somma - 0.96 * prec;      /* le labbra */
        prec = somma;
      }

      var picco = 0;
      for (i = 0; i < n; i++) picco = Math.max(picco, Math.abs(out[i]));
      if (picco > 0) {
        var q = 0.8 / picco;
        for (i = 0; i < n; i++) out[i] *= q;
      }
      return buf;
    }

    function eVocale(c) { return "aeiouàèéìòóù".indexOf(c) >= 0; }

    function leggi(testo) {
      var s = testo.toLowerCase().replace(/[^a-zàèéìòóù ]/g, "");
      var out = [], i = 0;
      while (i < s.length) {
        var c = s.charAt(i), d = s.charAt(i + 1), e = s.charAt(i + 2), f = null, salta = 1;
        if (c === "c" && d === "h") { f = "k"; salta = 2; }
        else if (c === "c" && (d === "i" || d === "e")) { f = "C"; salta = (d === "i" && eVocale(e)) ? 2 : 1; }
        else if (c === "c") f = "k";
        else if (c === "g" && d === "h") { f = "g"; salta = 2; }
        else if (c === "g" && d === "n") { f = "N"; salta = 2; }
        else if (c === "g" && d === "l" && e === "i") { f = "L"; salta = 3; }
        else if (c === "g" && (d === "i" || d === "e")) { f = "G"; salta = (d === "i" && eVocale(e)) ? 2 : 1; }
        else if (c === "g") f = "g";
        else if (c === "s" && d === "c" && (e === "i" || e === "e")) { f = "S"; salta = (e === "i" && eVocale(s.charAt(i + 3))) ? 3 : 2; }
        else if (c === "q") { out.push({ p: "k" }); f = "w"; salta = 2; }
        else if (c === "h") {
          var quante = 0;
          while (s.charAt(i + quante) === "h") quante++;
          var ultimo = out[out.length - 1];
          if (ultimo && SUONI[ultimo.p] && SUONI[ultimo.p].t === "voc") ultimo.lunga = Math.max(ultimo.lunga || 1, quante + 1);
          i += quante;
          continue;
        }
        else if (c === "z") { out.push({ p: "t" }); f = "s"; }
        else if (c === "à") f = "a";
        else if (c === "è") f = "E";
        else if (c === "é") f = "e";
        else if (c === "ì") f = "i";
        else if (c === "ò") f = "O";
        else if (c === "ó") f = "o";
        else if (c === "ù") f = "u";
        else if (SUONI[c]) f = c;
        if (!f) { i += salta; continue; }
        if (eVocale(c)) {
          var n = 1;
          while (s.charAt(i + n) === c) n++;
          out.push(n > 1 ? { p: f, lunga: n } : { p: f });
          i += n;
          continue;
        }
        if (s.charAt(i + salta) === c) { out.push({ p: f, doppia: true }); i += salta + 1; continue; }
        out.push({ p: f });
        i += salta;
      }
      /* i e u davanti a vocale diventano semivocali: vieni, guarda */
      for (var k = 0; k < out.length - 1; k++) {
        var q = out[k], dopo = out[k + 1];

        if (q.p === "i") q.p = "j";
        else if (q.p === "u") q.p = "w";
      }
      return out;
    }

    function costruisciFrase(testo, vc) {
      var sr = ctx.sampleRate;
      var seq = leggi(testo);
      if (!seq.length) return null;

      /* accento sulla penultima vocale di ogni parola */
      var parola = [];
      for (var q = 0; q <= seq.length; q++) {
        var x = seq[q];
        if (!x || x.p === " ") {
          var voc = [];
          for (var z = 0; z < parola.length; z++) if (SUONI[parola[z].p].t === "voc") voc.push(parola[z]);
          if (voc.length) voc[Math.max(0, voc.length - 2)].accento = true;
          parola = [];
        } else parola.push(x);
      }

      var segs = [], totale = 0, i, j, k;
      for (i = 0; i < seq.length; i++) {
        var su = SUONI[seq[i].p], dd = su.d;
        if (seq[i].lunga) dd = 0.16 + 0.12 * Math.min(5, seq[i].lunga);
        else if (seq[i].accento) dd *= 1.5;
        if (seq[i].doppia) dd *= 1.8;
        dd *= vc.ritmo;
        segs.push({ s: su, d: dd, accento: !!seq[i].accento, lunga: seq[i].lunga || 0, inizio: totale });
        totale += dd;
      }
      totale += 0.28;

      var n = Math.ceil(sr * totale);
      var buf = ctx.createBuffer(1, n, sr);
      var out = buf.getChannelData(0);
      var F0a = new Float32Array(n), F1a = new Float32Array(n), F2a = new Float32Array(n), F3a = new Float32Array(n);
      var amp = new Float32Array(n), voz = new Float32Array(n), nas = new Float32Array(n);
      var rum = new Float32Array(n), scop = new Float32Array(n);
      var bF = new Float32Array(n), bQ = new Float32Array(n), tono = new Float32Array(n);

      for (i = 0; i < n; i++) tono[i] = vc.f0 * (1.04 - 0.2 * (i / n));

      for (k = 0; k < segs.length; k++) {
        var sg = segs[k], i0 = Math.floor(sg.inizio * sr), len = Math.max(1, Math.floor(sg.d * sr));
        var tp = sg.s.t;
        for (i = 0; i < len && i0 + i < n; i++) {
          var idx = i0 + i, u = i / len;
          F0a[idx] = sg.s.F[0] * vc.tratto;
          F1a[idx] = sg.s.F[1] * vc.tratto;
          F2a[idx] = sg.s.F[2] * vc.tratto;
          F3a[idx] = sg.s.F[3] * vc.tratto;
          if (sg.lunga) tono[idx] *= 1 + 0.12 * Math.sin(Math.PI * Math.min(1, u * 1.15)) - 0.14 * u * u;
          else if (sg.accento) tono[idx] *= 1 + 0.1 * Math.sin(Math.PI * u);
          if (tp === "voc") { amp[idx] = sg.accento ? 1 : 0.9; voz[idx] = 1; }
          else if (tp === "sem") { amp[idx] = 0.75; voz[idx] = 1; }
          else if (tp === "nas") { amp[idx] = 0.55; voz[idx] = 1; nas[idx] = 1; }
          else if (tp === "liq") { amp[idx] = 0.7; voz[idx] = 1; }
          else if (tp === "tap") { amp[idx] = 0.35 + 0.8 * Math.abs(u - 0.5); voz[idx] = 1; }
          else if (tp === "fri") {
            amp[idx] = sg.s.sordo ? 0 : 0.35;
            voz[idx] = sg.s.sordo ? 0 : 1;
            rum[idx] = sg.s.rumore; bF[idx] = sg.s.banda[0]; bQ[idx] = sg.s.banda[1];
          } else if (tp === "occ" || tp === "aff") {
            var chiusa = tp === "occ" ? 0.72 : 0.45;
            if (u < chiusa) { amp[idx] = sg.s.sordo ? 0 : 0.12; voz[idx] = sg.s.sordo ? 0 : 1; }
            else if (u < chiusa + 0.12) { scop[idx] = sg.s.scoppio[1]; bF[idx] = sg.s.scoppio[0]; bQ[idx] = 1.4; }
            else if (tp === "aff") { rum[idx] = sg.s.rumore; bF[idx] = sg.s.banda[0]; bQ[idx] = sg.s.banda[1]; amp[idx] = sg.s.sordo ? 0 : 0.3; voz[idx] = sg.s.sordo ? 0 : 1; }
            else { amp[idx] = 0.1; voz[idx] = sg.s.sordo ? 0 : 0.4; }
          }
        }
      }

      /* tutto scivola: e' questo che toglie gli scatti */
      function lisc(arr, tau) {
        var a = Math.exp(-1 / (tau * sr)), y = arr[0];
        for (var q2 = 0; q2 < n; q2++) { y = a * y + (1 - a) * arr[q2]; arr[q2] = y; }
      }
      lisc(F0a, 0.022); lisc(F1a, 0.022); lisc(F2a, 0.022); lisc(F3a, 0.022);
      lisc(amp, 0.012); lisc(voz, 0.010); lisc(nas, 0.020);
      lisc(bF, 0.006); lisc(bQ, 0.006); lisc(rum, 0.008);

      var poli = [{y1:0,y2:0},{y1:0,y2:0},{y1:0,y2:0},{y1:0,y2:0},{y1:0,y2:0}];
      var banda = { y1: 0, y2: 0 };
      var fase = 0, nn = 0, prec = 0, drift = 0, zx1 = 0, zx2 = 0;
      var a1 = [], a2 = [], A = [], gn = 0, thz = 0, ba1 = 0, ba2 = 0, bA = 0;
      for (i = 0; i < n; i++) {
        if (i % 32 === 0) {
          var Fs = [F0a[i], F1a[i], F2a[i], F3a[i], 1000 * vc.tratto];
          var Bs = [95, 130, 180, 250, 120];
          a1 = []; a2 = []; A = [];
          for (j = 0; j < 5; j++) {
            var r = Math.exp(-Math.PI * Bs[j] / sr), th = 2 * Math.PI * Math.max(120, Fs[j]) / sr;
            a1.push(2 * r * Math.cos(th)); a2.push(-r * r); A.push(1 - a1[j] - a2[j]);
          }
          gn = nas[i] * 0.6;
          thz = 2 * Math.PI * (820 * vc.tratto) / sr;
          var bf = Math.max(300, bF[i]), bq = Math.max(0.6, bQ[i]);
          var rr = Math.exp(-Math.PI * (bf / bq) / sr), tt = 2 * Math.PI * bf / sr;
          ba1 = 2 * rr * Math.cos(tt); ba2 = -rr * rr; bA = 1 - ba1 - ba2;
        }
        if (i % 200 === 0) drift = drift * 0.9 + gauss() * 0.006;
        var f0 = tono[i] * (1 + drift + 0.012 * Math.sin(2 * Math.PI * 4.6 * i / sr));
        if (fase <= 0) { fase = sr / f0 * (1 + gauss() * 0.012); nn = 0; }
        var T1 = fase * 0.44, T2 = fase * 0.16, g = 0;
        if (nn < T1) g = 0.5 * (1 - Math.cos(Math.PI * nn / T1));
        else if (nn < T1 + T2) g = Math.cos(Math.PI * (nn - T1) / (2 * T2));
        nn++; fase--;

        var x = g * voz[i] * amp[i];
        if (gn > 0) {
          var zz = x - 2 * 0.96 * Math.cos(thz) * zx1 + 0.9216 * zx2;
          zx2 = zx1; zx1 = x;
          x = x * (1 - gn) + zz * gn;
        } else { zx2 = zx1; zx1 = x; }
        var orale = x, ff, yy;
        for (j = 0; j < 4; j++) {
          ff = poli[j];
          yy = A[j] * orale + a1[j] * ff.y1 + a2[j] * ff.y2;
          ff.y2 = ff.y1; ff.y1 = yy; orale = yy;
        }
        var nsl = 0;
        if (gn > 0) { ff = poli[4]; nsl = A[4] * x + a1[4] * ff.y1 + a2[4] * ff.y2; ff.y2 = ff.y1; ff.y1 = nsl; }
        var bianco = (Math.random() * 2 - 1) * (rum[i] + scop[i] * 1.2);
        var yb = bA * bianco + ba1 * banda.y1 + ba2 * banda.y2;
        banda.y2 = banda.y1; banda.y1 = yb;
        var somma = orale + nsl * gn * 0.6 + yb * 0.9;
        out[i] = somma - 0.96 * prec;
        prec = somma;
      }

      var picco = 0;
      for (i = 0; i < n; i++) picco = Math.max(picco, Math.abs(out[i]));
      if (picco > 0) { var qq = 0.78 / picco; for (i = 0; i < n; i++) out[i] *= qq; }
      return buf;
    }

    var VOCINE = [
      { f0: 340, tratto: 1.00, ritmo: 1.0 },
      { f0: 385, tratto: 1.06, ritmo: 0.95 },
      { f0: 315, tratto: 0.95, ritmo: 1.05 }
    ];
    var fraseFatta = {};

    function voce(frase) {
      if (!ctx) return;
      var vc = VOCINE[Math.floor(Math.random() * VOCINE.length)];
      var chiave = frase + "|" + vc.f0;
      if (!fraseFatta[chiave]) fraseFatta[chiave] = costruisciFrase(frase, vc);
      var b = fraseFatta[chiave];
      if (!b) return;
      var src = ctx.createBufferSource();
      src.buffer = b;
      var g = ctx.createGain();
      g.gain.value = 0.75;
      src.connect(g);
      g.connect(master);
      src.start();
    }

    return {
      attivo: function () { return acceso; },
      accendiVoci: function (si) {
        vociAccese = !!si;
        if (vociAccese) {
          apri();
          if (ctx && ctx.state === "suspended") ctx.resume();
          prossimaVoce = performance.now() + 1500;
        }
      },
      accendi: function (si) {
        acceso = !!si;
        if (acceso) {
          if (opz.sintetico) {
            apri();
            if (ctx && ctx.state === "suspended") ctx.resume();
            prossimaRisata = performance.now() + 800;
          }
          if (opz.file) {
            if (!traccia) {
              traccia = new Audio(opz.file);
              traccia.preload = "auto";
              traccia.loop = opz.modo === "anello";
              traccia.volume = opz.volume;
            }
            if (opz.modo === "anello") {
              var pr = traccia.play();
              if (pr && pr.catch) pr.catch(function () {});
            } else {
              prossimoFile = performance.now() + 1500;
            }
          }
        } else if (traccia) {
          traccia.pause();
        }
      },
      rimbalzo: function (p) {
        if (!acceso || !ctx || document.hidden) return;
        var ora = performance.now();
        if (ora - ultimoTuc < 240) return;
        ultimoTuc = ora;
        tuc(300 / p.profondita, Math.min(1, p.profondita));
        if (Math.random() < 0.24 && ora - ultimaRisata > 900) {
          ultimaRisata = ora;
          risatina(360 + Math.random() * 90);
        }
      },
      battito: function () {
        var adesso = performance.now();
        /* la registrazione vera: una risata ogni tanto, non un tappeto continuo */
        if (acceso && traccia && opz.modo !== "anello" && !document.hidden && adesso > prossimoFile) {
          prossimoFile = adesso + 8000 + Math.random() * 12000;
          try { traccia.currentTime = 0; } catch (e) {}
          var pf = traccia.play();
          if (pf && pf.catch) pf.catch(function () {});
        }
        if (vociAccese && !document.hidden && adesso > prossimaVoce) {
          prossimaVoce = adesso + 5000 + Math.random() * 6000;
          voce(opz.frasi[Math.floor(Math.random() * opz.frasi.length)]);
        }
        if (!acceso || !ctx || document.hidden) return;
        var ora = performance.now();
        if (ora < prossimaRisata) return;
        prossimaRisata = ora + 1800 + Math.random() * 3200;
        ultimaRisata = ora;
        risatina(360 + Math.random() * 90);
      }
    };
  }

  var scene = [];
  window.PalloncinISfogline = {
    suono: function (si) {
      scene.forEach(function (s) { s.accendi(si); });
    },
    voci: function (si) {
      scene.forEach(function (s) { s.accendiVoci(si); });
    }
  };

  /* ---------- una scena per ogni contenitore ---------- */
  function avvia(nodo) {
    if (nodo.dataset.avviato) return;
    nodo.dataset.avviato = "1";

    var opz = {
      numero: Math.max(1, Math.min(120, parseInt(nodo.dataset.numero, 10) || 18)),
      velocita: parseFloat(nodo.dataset.velocita) || 1,
      dimensione: parseFloat(nodo.dataset.dimensione) || 1,
      filo: nodo.dataset.filo !== "no",
      puntatore: nodo.dataset.puntatore !== "no",
      opacita: nodo.dataset.opacita === undefined ? 1 : parseFloat(nodo.dataset.opacita),
      sezione: nodo.dataset.strato === "sezione",
      foto: [],
      quotaFoto: 0
    };

    /* foto dall'attributo e dalle <img> messe dentro al contenitore */
    (nodo.dataset.foto || "").split(",").forEach(function (u) {
      u = u.trim();
      if (u) opz.foto.push(u);
    });
    Array.prototype.slice.call(nodo.querySelectorAll("img")).forEach(function (im) {
      var u = im.currentSrc || im.getAttribute("src");
      if (u) opz.foto.push(u);
      im.remove();
    });
    if (opz.foto.length) {
      var q = parseFloat(nodo.dataset.fotoQuota);
      opz.quotaFoto = isNaN(q) ? 1 : Math.max(0, Math.min(1, q));
    }

    var vol = parseFloat(nodo.dataset.suonoVolume);
    var frasi = (nodo.dataset.vociFrasi || "guarda come volo|ohhh che bellooooo|vieni anche tuuuuu|su dai vieni che ci divertiamooooo|che bella sfoglia")
      .split("|").map(function (f) { return f.trim(); }).filter(Boolean);
    var suono = creaSuono({
      sintetico: nodo.dataset.suono === "si",
      file: (nodo.dataset.suonoFile || "").trim(),
      volume: isNaN(vol) ? 0.35 : Math.max(0, Math.min(1, vol)),
      modo: nodo.dataset.suonoModo === "anello" ? "anello" : "ogni-tanto",
      frasi: frasi
    });
    scene.push(suono);

    /* i browser lasciano suonare solo dopo il primo gesto del visitatore */
    if (nodo.dataset.suono === "si" || nodo.dataset.voci === "si" || (nodo.dataset.suonoFile || "").trim()) {
      var sveglia = function () {
        if (nodo.dataset.suono === "si" || (nodo.dataset.suonoFile || "").trim()) suono.accendi(true);
        if (nodo.dataset.voci === "si") suono.accendiVoci(true);
        ["pointerdown", "keydown", "touchstart"].forEach(function (e) {
          window.removeEventListener(e, sveglia);
        });
      };
      ["pointerdown", "keydown", "touchstart"].forEach(function (e) {
        window.addEventListener(e, sveglia, { once: false });
      });
    }

    nodo.style.position = opz.sezione ? "absolute" : "fixed";
    nodo.style.top = nodo.style.left = nodo.style.right = nodo.style.bottom = "0";
    nodo.style.overflow = "hidden";
    nodo.style.pointerEvents = "none";
    nodo.style.opacity = String(opz.opacita);
    nodo.style.zIndex = nodo.dataset.livello || (opz.sezione ? "0" : "-1");
    if (opz.sezione) {
      var padre = nodo.parentElement;
      if (padre && getComputedStyle(padre).position === "static") padre.style.position = "relative";
    }

    var palloncini = [];
    var contatore = 0;
    var semeScena = Math.floor(Math.random() * 1e9);
    var L = 0, H = 0;
    var visibile = true;
    var puntatore = { x: -9999, y: -9999, attivo: false };
    var motoRidotto = window.matchMedia("(prefers-reduced-motion: reduce)").matches;

    function misuraScena() {
      var r = nodo.getBoundingClientRect();
      L = r.width || window.innerWidth;
      H = r.height || window.innerHeight;
    }

    function misura(p) {
      var lato = Math.min(L, H);
      p.larghezza = Math.max(46, lato * 0.15 * p.profondita * opz.dimensione);
      p.raggio = p.larghezza * 0.44;
      p.el.style.width = p.larghezza + "px";
    }

    function nuovo(i) {
      var r = seme((semeScena ^ Math.imul(i + 1, 2654435761)) >>> 0);
      r(); r(); r();
      var profondita = 0.55 + Math.random() * 0.6;
      var el = document.createElement("div");
      el.style.position = "absolute";
      el.style.top = el.style.left = "0";
      el.style.transformOrigin = "50% 33.333%";
      el.style.willChange = "transform";
      el.style.filter = "drop-shadow(0 8px 12px rgba(42,31,23,.16))";
      var conFoto = opz.foto.length && r() < opz.quotaFoto;
      el.innerHTML = conFoto
        ? disegnaFoto(r, ++contatore, opz.filo, opz.foto[i % opz.foto.length])
        : disegnaVolto(r, ++contatore, opz.filo);
      el.firstChild.setAttribute("style", "display:block;width:100%;height:auto");
      nodo.appendChild(el);

      var angolo = Math.random() * Math.PI * 2;
      var base = 0.35 + Math.random() * 0.7;
      var p = {
        el: el,
        profondita: profondita,
        larghezza: 0,
        raggio: 0,
        x: (0.08 + Math.random() * 0.84) * L,
        y: (0.08 + Math.random() * 0.84) * H,
        vx: Math.cos(angolo) * base * profondita,
        vy: Math.sin(angolo) * base * profondita,
        fase: Math.random() * Math.PI * 2,
        ondeggio: 3 + Math.random() * 6,
        ritmo: 0.006 + Math.random() * 0.008
      };
      misura(p);
      el.style.zIndex = String(Math.round(profondita * 100));
      return p;
    }

    var ultimo = performance.now();

    function passo(ora) {
      var dt = Math.min(48, ora - ultimo) / 16.6667;
      ultimo = ora;

      if (visibile && !document.hidden) {
        for (var i = 0; i < palloncini.length; i++) {
          var p = palloncini[i];
          var v = opz.velocita * (motoRidotto ? 0.3 : 1);
          p.x += p.vx * dt * v;
          p.y += p.vy * dt * v;

          if (opz.puntatore && puntatore.attivo) {
            var dx = p.x - puntatore.x, dy = p.y - puntatore.y;
            var d2 = dx * dx + dy * dy, R = 170;
            if (d2 < R * R) {
              var d = Math.sqrt(d2) || 1, f = (1 - d / R) * 0.7;
              p.vx += (dx / d) * f;
              p.vy += (dy / d) * f;
            }
          }

          var urto = false;
          if (p.x < p.raggio) { p.x = p.raggio; p.vx = Math.abs(p.vx); p.vy += (Math.random() - 0.5) * 0.12; urto = true; }
          if (p.x > L - p.raggio) { p.x = L - p.raggio; p.vx = -Math.abs(p.vx); p.vy += (Math.random() - 0.5) * 0.12; urto = true; }
          if (p.y < p.raggio) { p.y = p.raggio; p.vy = Math.abs(p.vy); p.vx += (Math.random() - 0.5) * 0.12; urto = true; }
          if (p.y > H - p.raggio) { p.y = H - p.raggio; p.vy = -Math.abs(p.vy); p.vx += (Math.random() - 0.5) * 0.12; urto = true; }
          if (urto) suono.rimbalzo(p);

          var s = Math.hypot(p.vx, p.vy);
          var max = 2.4 * p.profondita, min = 0.22 * p.profondita;
          if (s > max) { p.vx *= max / s; p.vy *= max / s; }
          if (s < min && s > 0) { p.vx *= min / s; p.vy *= min / s; }

          p.fase += p.ritmo * dt * (motoRidotto ? 0.4 : 1);
          var rot = motoRidotto ? 0 : Math.sin(p.fase) * p.ondeggio;
          p.el.style.transform =
            "translate3d(" + (p.x - p.larghezza / 2) + "px," + (p.y - p.larghezza / 2) + "px,0) rotate(" + rot.toFixed(2) + "deg)";
        }
        suono.battito();
      }
      requestAnimationFrame(passo);
    }

    misuraScena();
    for (var i = 0; i < opz.numero; i++) palloncini.push(nuovo(i));

    window.addEventListener("resize", function () {
      misuraScena();
      palloncini.forEach(function (p) {
        misura(p);
        p.x = Math.min(Math.max(p.x, p.raggio), L - p.raggio);
        p.y = Math.min(Math.max(p.y, p.raggio), H - p.raggio);
      });
    });

    if (opz.puntatore) {
      window.addEventListener("pointermove", function (e) {
        var r = nodo.getBoundingClientRect();
        puntatore.x = e.clientX - r.left;
        puntatore.y = e.clientY - r.top;
        puntatore.attivo = true;
      });
      window.addEventListener("pointerleave", function () { puntatore.attivo = false; });
    }

    /* ferma il disegno quando la scena non si vede: niente batteria sprecata */
    if (window.IntersectionObserver) {
      new IntersectionObserver(function (voci) {
        visibile = voci[0].isIntersecting;
      }).observe(nodo);
    }

    requestAnimationFrame(passo);
  }

  function avviaTutti() {
    var nodi = document.querySelectorAll("[data-palloncini-sfogline]");
    for (var i = 0; i < nodi.length; i++) avvia(nodi[i]);
  }

  if (document.readyState === "loading") {
    document.addEventListener("DOMContentLoaded", avviaTutti);
  } else {
    avviaTutti();
  }
})();
</script>

La pagina rispetta chi ha chiesto meno animazioni nelle impostazioni del sistema: in quel caso i palloncini rallentano e smettono di dondolare. Quando la scena esce dallo schermo il disegno si ferma, per non consumare batteria.
